# 🧠 Institutional Memory Bot

An AI chatbot that remembers everything a company ever decided, discussed, or documented — across Confluence, Slack, GitHub, Jira, Email, and meeting transcripts.

**Stack:** Mistral-7B-Instruct (4-bit) · ChromaDB · Neo4j AuraDB · LangGraph · LangChain · Streamlit
